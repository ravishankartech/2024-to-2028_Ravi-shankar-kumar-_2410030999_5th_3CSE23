## 📖 About the Internship

The **Java Full Stack Development With Project** internship is an industry-oriented, 8-week program that combines self-paced learning modules with a hands-on capstone project — covering everything from Core Java fundamentals to building and deploying a full stack web application.

**Program Partners:** Ministry of Education · AICTE · National Internship Portal · EduSkills Academy

- **Front-end:** HTML5, CSS3, JavaScript
